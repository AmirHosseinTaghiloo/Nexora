## 📌 معرفی پروژه

**NEXORA** یک فروشگاه اینترنتی مدرن و چندصفحه‌ای است که با هدف ایجاد یک تجربه خرید سریع، زیبا و حرفه‌ای طراحی شده است.

این پروژه با استفاده از معماری مدرن  Vue و Nuxt توسعه داده شده و شامل بخش‌های مختلف فروشگاهی مانند محصولات، دسته‌بندی‌ها، سبد خرید، علاقه‌مندی‌ها، حساب کاربری، نظرات کاربران و صفحه جزئیات محصول است.

تمرکز اصلی پروژه روی:

- 🎨 طراحی مدرن
- 📱 طراحی Responsive
- ⚡ سرعت بالا
- 🧩 ساختار Component-Based
- 🛒 تجربه خرید حرفه‌ای
- 🔎 جستجو و مدیریت محصولات
- ❤️ سیستم علاقه‌مندی
- ⭐ امتیازدهی و نظرات کاربران
- 📰 سیستم ولاگ و اخبار
است.
